실제 그리퍼로 물체 잡기 작업 기록 1
====================================

1. 작업 목적

기존 시뮬레이션에서는 그리퍼가 빨간 블록 가까이에 도달하면 블록의 위치를
그리퍼 위치로 강제로 복사하는 방식으로 물체를 이동시켰다. 이 방식을 제거하고,
실제 로봇처럼 양쪽 그리퍼가 블록에 직접 닿아 마찰력으로 물체를 잡도록 변경했다.


2. 기존 방식의 문제점

- 그리퍼와 블록 사이에 실제 접촉이 없어도 일정 거리 안에 들어오면 물체가 붙었다.
- 블록의 qpos와 qvel을 프로그램에서 직접 변경했다.
- 그리퍼가 물체를 정확하게 누르지 않아도 운반할 수 있었기 때문에 실제 로봇의
  파지 동작을 반영하지 못했다.
- 그리퍼와 블록의 접촉면이 평행하지 않아 실제 로봇에서는 미끄러짐이나 파지
  실패가 발생할 가능성이 있었다.


3. 접촉 기반 파지 구현

jdcobot200.xml의 양쪽 손가락 끝에 실제 충돌 판정용 박스 지오메트리를 추가했다.

- left_finger_pad
- right_finger_pad

각 접촉 패드는 다음 물리 속성을 사용한다.

- contype="1"
- conaffinity="1"
- condim="4"
- friction="1.5 0.05 0.001"

기존 그리퍼 메시 지오메트리는 시각화 용도로 유지하고, 새 접촉 패드가 블록과
충돌하고 마찰력을 발생시키도록 구성했다. 이 방식은 so101_new_calib.xml의
손가락 접촉 패드 구성을 참고하여 구현했다.


4. 강제 부착 방식 제거

jdcobot200_pick_and_place.py에서 다음 강제 부착 관련 기능을 제거했다.

- Phase의 attach 및 detach 속성
- _attach_block()
- _detach_block()
- _hold_attached_block()
- 블록 freejoint의 qpos 및 qvel 직접 변경

이제 블록의 위치와 자세는 프로그램에서 강제로 변경되지 않는다. 블록은 MuJoCo의
접촉력, 그리퍼 압력, 마찰력과 중력에 의해서만 움직인다.


5. 그리퍼 열림 및 닫힘 설정

jdcobot200_pick_and_place.py에 다음 값을 설정했다.

GRIPPER_OPEN = 0.45
GRIPPER_CLOSED = -0.40

닫힘 명령을 충분히 주어 양쪽 접촉 패드가 블록을 눌러 운반할 수 있도록 했다.
물체를 잡는 동안에는 닫힘 명령을 유지하고, 배치 지점에서 그리퍼를 열어 물체를
자연스럽게 내려놓는다.


6. 파지 높이 수정

기존에는 실제 블록 중심보다 높은 위치에서도 물체가 자동으로 붙을 수 있었다.
직접 접촉 방식에서는 그리퍼가 실제 블록 높이까지 내려가야 하므로 다음과 같이
설정했다.

BLOCK_HALF_HEIGHT = 0.015
GRASP_Z = BLOCK_HALF_HEIGHT + 0.003

따라서 그리퍼의 파지 기준 높이는 0.018 m이다.


7. 블록과 그리퍼 평행 정렬

블록은 scene.xml에서 작업대 좌표축과 평행하도록 yaw를 0으로 고정했다.

<body name="red_block" pos="0.22 -0.10 0.016" euler="0 0 0">

위치 전용 IK는 그리퍼의 yaw 방향을 보장하지 않으므로 wrist_roll 값을 수동으로
고정했다.

WRIST_ROLL_PARALLEL = 1.0085

이 값은 약 57.78도이다. IK가 계산한 관절 명령 중 wrist_roll 값을 매 제어
스텝마다 위 값으로 덮어써서, 픽·이동·배치 과정 전체에서 그리퍼 방향을 유지한다.

시뮬레이션에서 측정한 양쪽 접촉면 방향은 다음과 같다.

- 왼쪽 접촉면 yaw: -90.69도
- 오른쪽 접촉면 yaw: -89.22도

블록의 Y 방향 접촉면은 ±90도이므로 평면상 정렬 오차는 약 ±0.8도 이내이다.

실제 로봇에 적용할 때 캘리브레이션 차이가 있으면 다음 값을 조금씩 조절한다.

WRIST_ROLL_PARALLEL = 1.0085


8. 수정한 파일

- jdcobot200.xml
  양쪽 그리퍼 손가락에 실제 접촉 패드를 추가했다.

- jdcobot200_pick_and_place.py
  강제 부착 코드를 제거하고 접촉 기반 파지, 파지 높이 및 wrist_roll 수동 고정을
  적용했다.

- scene.xml
  빨간 블록을 작업대 좌표축과 평행하도록 yaw 0으로 설정했다.


9. 실행 방법

GUI 시뮬레이션:

python3 jdcobot200_pick_and_place.py

창 없는 검증 실행:

python3 jdcobot200_pick_and_place.py --headless --max-time 35


10. 최종 검증 결과

- 블록 강제 위치 변경 없이 실제 접촉력으로 파지 성공
- 블록 들어 올리기 및 이동 성공
- 배치 지점에서 그리퍼를 열어 물체 해제 성공
- 블록과 그리퍼 접촉면의 평면상 평행 정렬 확인
- 최종 배치 XY 오차: 약 19.6 mm

현재 구현은 물체 위치와 방향이 scene.xml에 미리 정해진 수동 설정 방식이다.
카메라로 물체 방향을 검출하는 자동 정렬 방식은 포함하지 않는다. 실제 로봇에서는
블록을 작업대 기준축과 평행하게 놓고 wrist_roll의 캘리브레이션 값을 맞춰야 한다.
