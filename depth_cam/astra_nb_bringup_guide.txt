Orbbec Astra NB Depth Camera Bring-up 진행 기록
================================================

작성일: 2026-08-28
환경:
  - 운영체제: Ubuntu 22.04
  - ROS: ROS 2 Humble
  - 작업 폴더: /home/robo/jdcobot200_imitation_learning/depth_cam


1. 카메라 확인 결과
-------------------

USB에서 다음 장치가 정상적으로 발견되었습니다.

  - 제조사/모델: Orbbec Astra
  - USB VID:PID: 2bc5:0401
  - 제품명: Astra NB
  - 카메라 시리얼 번호: 21031110051

Orbbec 전용 OpenNI2 런타임에서 다음과 같이 탐지되었습니다.

  - Device: Astra
  - URI 예시: 2bc5/0401@1/11

USB를 다시 연결하면 URI 마지막 장치 번호는 달라질 수 있으며 정상입니다.


2. 설치 및 빌드 내용
-------------------

다음 구성요소를 작업 폴더 내부에 준비하고 빌드했습니다.

  - Orbbec 공식 ROS 2 Astra 카메라 드라이버
  - Astra용 Orbbec OpenNI2 런타임 및 센서 플러그인
  - libuvc 로컬 빌드
  - ROS 2 image_publisher 의존 패키지

Ubuntu 기본 OpenNI2만 사용했을 때는 Astra 장치를 발견하지 못했기 때문에,
Astra 전용 OpenNI2 런타임을 포함하는 Orbbec 드라이버를 사용했습니다.

libuvc가 작업 폴더의 local/lib에 설치되므로 setup_env.bash가 필요한
환경 변수를 자동으로 설정합니다.


3. USB 권한 설정(최초 한 번)
----------------------------

아래 명령은 관리자 비밀번호가 필요합니다.

  cd /home/robo/jdcobot200_imitation_learning/depth_cam

  sudo cp src/ros2_astra_camera/astra_camera/scripts/56-orbbec-usb.rules \
    /etc/udev/rules.d/56-orbbec-usb.rules
  sudo udevadm control --reload-rules
  sudo udevadm trigger

명령 실행 후 카메라 USB를 뺐다가 다시 연결합니다.

권한 규칙이 적용되지 않으면 다음 오류가 발생합니다.

  Access denied (insufficient permissions)


4. 카메라 실행
--------------

터미널 1에서 실행합니다.

  cd /home/robo/jdcobot200_imitation_learning/depth_cam
  ./bringup_astra.bash

정상 실행 시 로그에서 다음 내용을 확인할 수 있습니다.

  - Found 1 devices
  - Device connected: Astra
  - depth is started
  - color is started
  - device started

카메라 실행을 종료하려면 터미널 1에서 Ctrl+C를 누릅니다.


5. 영상 확인
------------

카메라가 실행 중인 상태에서 새 터미널(터미널 2)을 열고 실행합니다.

  cd /home/robo/jdcobot200_imitation_learning/depth_cam
  source setup_env.bash
  ros2 run rqt_image_view rqt_image_view

rqt_image_view 상단의 토픽 선택 메뉴에서 다음 토픽을 선택합니다.

컬러 영상:

  /camera/color/image_raw

깊이 영상:

  /camera/depth/image_raw

깊이 영상은 16비트 거리 영상이므로 검게 보일 수 있습니다. 이 경우
rqt_image_view에서 "Normalize range"를 체크합니다. 범위를 직접 지정할 수
있다면 약 500~5000으로 설정합니다.


6. 발행 토픽
-------------

확인된 주요 토픽은 다음과 같습니다.

  /camera/color/camera_info
  /camera/color/image_raw
  /camera/depth/camera_info
  /camera/depth/image_raw
  /camera/depth/points
  /camera/ir/camera_info
  /camera/ir/image_raw
  /tf
  /tf_static

컬러와 IR 스트림을 동시에 활성화하면 Astra 하드웨어 제약으로 드라이버가
IR 스트림을 비활성화할 수 있습니다. 기본 실행 설정은 컬러와 깊이 영상을
우선 사용합니다.


7. 검증 결과
-------------

Depth 영상:

  - 해상도: 640 x 480
  - 설정 FPS: 30 Hz
  - 측정 수신률: 약 25~29 Hz
  - ROS encoding: 16UC1
  - 거리 단위: mm
  - 확인된 유효 거리 범위: 829~9851 mm
  - 확인 당시 유효 픽셀: 140492 / 307200

Color 영상:

  - 해상도: 640 x 480
  - 설정 FPS: 30 Hz

Depth point cloud:

  - /camera/depth/points


8. 상태 확인 명령
-----------------

새 터미널에서 먼저 환경을 불러옵니다.

  cd /home/robo/jdcobot200_imitation_learning/depth_cam
  source setup_env.bash

노드 확인:

  ros2 node list

토픽 확인:

  ros2 topic list

Depth 영상 발행률 확인:

  ros2 topic hz /camera/depth/image_raw

Color 영상 발행률 확인:

  ros2 topic hz /camera/color/image_raw

Depth 카메라 정보 확인:

  ros2 topic echo /camera/depth/camera_info --once


9. 작업 폴더의 실행 파일
------------------------

  setup_env.bash
    ROS 2 Humble, 현재 워크스페이스 및 로컬 libuvc 환경을 설정합니다.

  bringup_astra.bash
    필요한 환경을 설정하고 astra_camera의 astra.launch.xml을 실행합니다.


10. 가장 짧은 실행 순서
----------------------

터미널 1:

  cd /home/robo/jdcobot200_imitation_learning/depth_cam
  ./bringup_astra.bash

터미널 2:

  cd /home/robo/jdcobot200_imitation_learning/depth_cam
  source setup_env.bash
  ros2 run rqt_image_view rqt_image_view

뷰어에서 /camera/color/image_raw 또는 /camera/depth/image_raw를 선택합니다.
